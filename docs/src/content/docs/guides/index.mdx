Start with the Catalog API to find datasets, then use the Query API to retrieve the data you need.

| Guide | What you'll learn |
| --- | --- |
| [Making your first request](./first-request/) | Search the public Catalog and make a protected Query request for daily meter counts. |
| [Authentication](./authentication/) | Choose a sign-in flow, understand role-based access, and troubleshoot access errors. |
| [Connection Requirements](./connection-requirements/) | Connect securely, build requests, and plan for errors and version changes. |
| [Requests and results](./requests-and-results/) | Build valid requests, page and filter results, and retrieve downloads. |
| [Operating your client](./operating-your-client/) | Handle errors and retries, and prepare for API changes. |
| [SDKs and client libraries](./sdk-overview/) | Adapt an operation example or generate a client from OpenAPI. |

Use the [API reference](../reference/) for the parameters and response schemas of a specific operation. A published contract does not guarantee that the operation is deployed in your environment or enabled for your account.
