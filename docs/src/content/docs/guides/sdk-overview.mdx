---
title: SDKs and client libraries
description: Current status and future layout for Smart Data Repository SDKs.
---

No official SDKs or generated client libraries are published in this portal yet. The portal keeps API references versioned and separate from guides so that client libraries can be added later without changing the API contract URLs.

Until an SDK is announced here, use the published API reference directly and follow confirmed authentication guidance. Do not treat third-party or unpublished clients as official.
