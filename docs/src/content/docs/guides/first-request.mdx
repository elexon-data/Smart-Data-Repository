---
title: Making your first request
description: Prepare to make a request using a published API contract.
---

Start with the versioned [API reference](/reference/) and use the exact server URL, path, parameters, and request schema documented there. Authentication and environment-specific values must come from confirmed guidance; this portal does not assume a service hostname or that an endpoint is currently available.

The reference describes the API contract, not live service availability or account permissions. Do not send credentials until the applicable authentication instructions have been confirmed.
