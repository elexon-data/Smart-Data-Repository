## Status

The versioned API reference documents the security requirements and scopes included in each contract. Separate guidance for the authoritative identity provider, token acquisition flow, and environment-specific configuration has not yet been published here. Follow the API owner's confirmed instructions before attempting to authenticate.

Do not place client secrets, access tokens, or other credentials in source code, examples, issue reports, or shared configuration. This portal does not provide credentials.
