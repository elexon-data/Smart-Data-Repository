## Find and retrieve data

- **Catalog API:** Search for datasets without signing in. Use the metadata to understand what a dataset contains, its access level, and which related datasets are available.
- **Query API:** Retrieve data from a documented dataset operation. Query operations require an SDR access token with the right scope. Depending on the operation, you can get paginated results, download a file, or submit a job.

Read the [Connection Requirements](./guides/connection-requirements/) before integrating your application. They explain how to connect securely, build requests, and handle errors and API changes.
