Use **Catalog API v1** to search dataset metadata, fetch details, and look up lineage and related datasets. Use **Query API v1** to retrieve dataset records, make downloads, or submit and check download jobs where the operation supports them.

| Format | When to use it |
| --- | --- |
| Integrated reference | Look up an operation's path, parameters, security, response media types, and schemas. Copy a cURL, JavaScript, Python, TypeScript, or .NET example to adapt for your client. |
| OpenAPI YAML | Import the contract into an API tool, validate requests, or generate a client. |
| Standalone reference | Browse the complete contract for one API in a single page. |

<ContractStatus />

Before calling an operation, confirm which environment you can access. For protected calls, replace the example bearer token using the [authentication guide](../guides/authentication/). If you're new to the APIs, follow [Making your first request](../guides/first-request/).

Query authorization is role-based. The operation-specific scopes currently shown in the Query contract do not describe the authorization requirements; see the [authentication guide](../guides/authentication/) for the tsti token scope and access guidance.
